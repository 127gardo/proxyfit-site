コーチを探している方へ

まずは利用したいサービスを選び、目標や言語、指導スタイルが合う担当者を探しましょう。

ProxyFit オンライントレーニング

ProxyFitが提供するコーチングです。月額$49.99でプレミアムの全機能も利用できます。申し込みの承認後に、アプリ内でサブスクリプションを開始します。

個人トレーナー

公開リストから選ぶか、トレーナーコードで担当者を探します。サービス内容、料金、支払い方法は各トレーナーが設定します。

申し込みから、日々の使い方まで

気になる項目を開くと、詳しい手順を確認できます。

アプリ内でコーチを探すには？
  1. ホーム → コーチング → トレーナーを探しているを開きます。
  2. ProxyFitから指導を受けたい場合はProxyFitオンラインコーチング、自分で担当者を選びたい場合は個人トレーナーを選びます。
  3. 個人トレーナーは、名前・専門分野・地域・対応言語などで探せます。プロフィールを開き、指導歴やオンライン・対面の対応状況を確認しましょう。
  4. 担当者が決まっている場合は、検索欄にトレーナーコードを入力し、トレーナーコードで直接探すをタップします。共有されたプロフィールリンクからも開けます。公開リストに載っていないトレーナーも、この方法で探せます。
申し込みと支払いの流れは？
  1. 個人トレーナーの場合は、プロフィールのコーチングに申し込むをタップします。ProxyFit オンライントレーニングの場合は、その案内ページから申し込みに進みます。
  2. 質問フォームに、目標、経験、使える器具、トレーニングできる時間、配慮が必要なことなどを入力して送信します。
  3. アプリ内で申込状況を確認します。始める前に、受けられるサービスや気になる点をコーチと相談しましょう。
  4. ProxyFit オンライントレーニングは、承認後にアプリ内で支払います。個人トレーナーは、その担当者と料金・支払い方法を直接確認します。個人トレーナーの指導を受けるために、月額$49.99のProxyFit オンライントレーニングへ加入する必要はありません。

個人トレーナーの利用に、プレミアムが自動で付くわけではありません。履歴・分析・ルーティン・AIの利用枠は、料金プランでご確認ください。

コーチングでは何をしてもらえますか？
  • トレーニングの計画：目標に合わせたワークアウトやプログラムを、コーチング画面から確認できます。
  • 週ごとの振り返り：チェックインを通じて、実施状況や体調、回復の様子を伝えられます。
  • フィードバック：チャットでの相談、完了したトレーニングへのコメント、送った動画のフォーム確認に利用できます。
  • 進捗の共有：目標、トレーニング結果、進捗写真に加え、必要に応じて食事や健康記録も共有できます。

指導の頻度、連絡への対応、プランを見直すタイミングなどは、開始前に担当者と確認しましょう。個人トレーナーのサービス範囲は担当者ごとに異なります。

開始後はどの画面を使いますか？
  1. ホームから自分のコーチング画面を開きます。割り当てられたワークアウトの予定日と、種目ごとの指示を確認します。
  2. 通常のワークアウト記録で各種目を入力し、最後にワークアウト完了で確定します。割り当てに関連付けられた結果を、コーチも確認できます。
  3. 週次チェックインを提出し、必要なときは進捗写真やフォーム動画も送ります。質問はチャットで相談できます。
  4. 完了したワークアウトや食事の記録に戻ると、コーチの返信を確認できます。通知や!が、新しい情報を見つける目印になります。

フォーム確認用の動画は1本30秒まで、最大4本保存できます。新しい動画を追加したいときは、不要になった動画を削除してください。

食事や健康の記録も見てもらえますか？

はい。担当コーチは、入力された食事・健康記録を確認し、食事への返信や、1日のカロリー・栄養素の目標設定ができます。栄養と健康で、続けやすい項目だけ記録してください。

トレーナーの方へ

メニュー、記録、やり取りを一か所に。公開プロフィールで新しいクライアントを募ることも、案内した方だけとつながることもできます。

計画を作る

テンプレートやプログラムを作成し、日程を設定。クライアントごとに内容を調整できます。

結果を確認する

完了したトレーニング、チェックイン、目標、動画、共有された食事・健康記録を確認できます。

指導を整理する

クライアント画面、チャット、カレンダー、色分けされた対応状況で、次の作業を把握できます。

登録・公開設定・クライアント管理

トレーナーとして登録するには？
  1. ホーム → コーチング → パーソナルトレーナーとして利用するを開きます。
  2. 氏名、地域、オンライン・対面の対応、専門分野、対応言語、指導歴、自己紹介などを入力します。資格やプロフィール写真も、掲載したい情報を追加してください。
  3. 承認後に公開リストへの掲載を希望するか選び、申請を送信します。
  4. トレーナー機能の利用が承認されたら、トレーナーダッシュボードを開き、プロフィールを整えます。トレーナー機能の利用承認と、公開リストへの掲載承認は別の手続きです。
公開トレーナー一覧に載ると、どうなりますか？

掲載が承認されると、コーチング → トレーナーを探している → 個人トレーナーでプロフィールを見つけてもらえるようになります。興味を持ったユーザーが、内容を読んで申し込めます。

  1. 写真、自己紹介、専門分野、対応言語、地域など、見込み客に伝えたい情報をプロフィールに入力します。
  2. プロフィールから公開掲載の申請を送ります。掲載は、トレーナー機能の利用申請とは別にProxyFitが確認します。
  3. アプリ内で公開状況や審査メッセージを確認してください。公開後のプロフィール変更も、再確認の対象になることがあります。

公開されるのはトレーナーのプロフィールです。クライアントの個別記録が一覧に公開されることはありません。また、掲載によってProxyFitの担当コーチになるわけではなく、クライアントが自動で割り当てられることもありません。

公開せず、自分のクライアントだけに使えますか？

はい。プロフィールを非公開のまま保存し、トレーナーコードや共有リンクをクライアントへ案内できます。公開しない場合も、個人トレーナーの検索欄にコードを入力してトレーナーコードで直接探すをタップすれば、プロフィールを開けます。

クライアントには、そのプロフィールから申し込んでもらいます。ダッシュボードで内容を確認して承認すると、個人トレーナーとしての指導を開始できます。サービス内容や支払いは、クライアントと直接取り決めてください。

クライアントの何を見て、何を操作できますか？
担当クライアントの記録と、利用できる指導機能
確認できる情報 できること
ワークアウト・プログラム メニューの作成、日程設定、割り当て、調整ができます。完了した種目のセット・回数・重量・メモを確認し、フィードバックを残せます。
チェックイン・目標 週ごとの回答や目標の進捗を確認し、コメントや確認済み・完了の処理ができます。
食事・健康データ 入力された記録の確認、食事への返信、1日のカロリー・栄養素の目標設定ができます。食事や健康の記録自体はクライアントが入力します。
進捗写真・フォーム動画 共有された写真や動画を確認し、フィードバックできます。フォーム動画は1本30秒まで、最大4本保存できます。
メッセージ・更新情報 チャットでやり取りし、クライアント画面や通知、カレンダーで指導の状況を確認できます。

対象は、担当としてつながっているクライアントの情報です。トレーナープロフィールを公開しても、クライアントの記録が閲覧者に公開されることはありません。

日々の指導はどう進めますか？
  1. ダッシュボードからクライアントを開き、申込内容、目標、最近の結果、対応が必要な項目を確認します。
  2. テンプレートやプログラムを使ってメニューを準備し、ワークアウトと日程を割り当てます。トレーニングブロックで予定をまとめ、進捗に合わせて調整できます。
  3. 完了したトレーニング、週次チェックイン、フォーム動画、必要に応じて食事や健康記録を確認します。フィードバックを残し、変更点はチャットで相談できます。
  4. ダッシュボードとカレンダーで、次の予定や未対応の内容を確認します。再利用できるテンプレートは、複数のクライアントへのメニュー作成にも役立ちます。
ダッシュボードの色は何を表していますか？
  • 緑・対応はありません：現時点で対応が必要な項目がない状態です。
  • 青・対応が必要：次のワークアウトの割り当てやチェックインなど、通常の指導上の作業があります。
  • 赤・要対応：支払いや期限を過ぎたトレーニングなど、確認が必要な問題があります。
  • 紫・新しい申し込み：確認を待っている申込があります。

実際の理由はクライアントのカードで確認できます。詳しい判定条件は、ダッシュボードの?をご覧ください。
